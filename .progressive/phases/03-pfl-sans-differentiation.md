# Phase 03 — Product-specific differentiation on the Inter base

Status: active for scoping; no implementation accepted yet.

## Goal
Decide whether PFL Sans needs distinctive glyph or spacing changes beyond the licensed Inter
baseline, and define a small, testable scope before modifying any outlines.

## First gate
Review real text use and visual references with the product owner. Identify specific forms or
spacing that should differ, with measurable acceptance and preservation of Latin/Russian quality.
Do not resume the superseded plan to redesign all 164 original geometric glyphs by default.

## Constraints
Keep Inter/OFL provenance visible and v1/v2/v3 project compatibility explicit. A production
variable binary or larger editor workflow requires a separate decision.
