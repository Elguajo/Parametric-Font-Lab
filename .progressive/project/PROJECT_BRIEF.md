# Project Brief — Parametric Font Lab

Status: RESEARCHED; production not started

## Outcome
Build an original browser workbench for designing and exporting a high-quality parametric Geometric/Technical Sans with live preview, source presets and production-safe font output.

## First release
Latin basic and Russian Cyrillic including Ё/ё are one quality gate. Expose a small safe axis set, selected local glyph overrides and discrete construction variants. Export versioned source plus validated static OTF/TTF/WOFF2. Variable fonts follow after full-repertoire master compatibility.

## Constraints
No copied Metaflop/Bespoke GPL geometry or UI assets; no commercial-font import/morphing. Typographic quality, script fidelity, licensing and deterministic export take priority over arbitrary style breadth. Detailed scope and evidence: `research/font-lab/final/mvp-scope.md` and `research/font-lab/final/RESEARCH_REPORT.md`.
