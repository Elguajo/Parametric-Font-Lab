# Product roadmap from Phase 0

| Phase | Exit evidence |
|---|---|
| 0 — Research | This report, source/license manifest, reverse-spec, ADRs, three disposable spikes, machine summary |
| 1a — source/preview vertical slice | versioned schema, deterministic original recipes for H/O/a/0 and Н/О/а/о, one global axis + one local override + one switch, responsive browser glyph/specimen, Python static export, parity and shape tests |
| 1b — Geometric/Technical Sans V1 | full Latin + Russian Cyrillic target, five controlled axes, two switch families, chart/typewriter/presets/A-B, validated static OTF/TTF/WOFF2, native review |
| 2 — variable axis expansion | compatible masters; variable weight TTF then width/optical if quality passes, HVAR/feature/metrics validation |
| 3 — additional style engines | Neo Grotesk, Humanist Sans, authored Mono; each with its own grammar and script/quality gate |
| 4 — compatible style interpolation | only between authored compatible models; no arbitrary pair morphing |
| 5 — advanced scripts/plugin architecture | script modules beyond Russian Cyrillic/Latin and third-party engine interface after real demand/security design |

Each phase updates canonical `.progressive/project/ROADMAP.md` only after acceptance evidence. This research roadmap is the product proposal, not a second PCK status register.
