# ADR-008 — Mono control

Status: Proposed for Phase 1
Date: 2026-09-23

## Context and options

A: interpolate advances alone (cheap, poor rhythm); B: authored compatible proportional/mono masters with redrawn forms (costly, potential VF); C: separate mono engine from start (scope expansion).

## Evidence

Recursive source demonstrates curated mono/sans variation; spacing analysis shows narrow/wide forms need redesign. No PFL mono spike validates compatibility yet.

## Recommendation

B later, outside V1. Source schema reserves Mono, but V1 does not export it.

## Consequences

Positive: typographic quality. Cost: substantial authored masters/kerning. Revisit after Phase 2 weight/width pipeline quality.
