# Metaflop interaction model

**Source-derived:** `parameter_panel.slim` renders a slider from `data-range-from`, `data-range-to`, `data-default`; nerd mode renders editable numeric input with ±0.01 and ±0.1 buttons. `modulator.slim` renders reset, randomize (`flop it!`), undo, glyph arrows/chooser, chart, editable typewriter, font-size/text selectors, share, and OTF/webfont export. The saved DOM shows `undo` disabled in initial state, Bespoke selected, Glyph/Chart enabled and anatomy disabled.

**Pipeline observed in Ruby source:** parameter values are inserted into a temporary `font.mf`; `/modulator/preview` returns a base64 OTF for CSS `@font-face`; `font/create` persists parameter URL; export routes regenerate OTF/webfont ZIP. Preview generation has a 10 s timeout; export 25 s. Invalid METAFONT output yields a 404-like error message that the entered value is out of valid range. This is server regeneration, not local vector mutation.

**Source-confirmed client behavior:** [`modulator.js`](https://github.com/metaflop/metaflop-www/blob/036c26b9f58f1264dba61d3818b7fae6869141e7/assets/javascripts/modulator.js) debounces preview requests by 300 ms, fades preview boxes while loading, cancels an in-flight request, then replaces the embedded font-face rule. The slider is configured with a 0.01 step and keyboard `maxStep: 1`. Numeric Up/Down changes by 0.01; ± buttons change by 0.01 or 0.1. Numeric fields accept comma or period. Randomize samples each active parameter to 0.01 across its full declared range; reset loops over source defaults; undo stores settings in `sessionStorage` and deduplicates consecutive states. Changing metafont reloads parameter panel and glyph chooser, clears history, then previews. The glyph chooser wraps at ends. These are implementation facts, not a dynamic browser observation.

Share first creates/reuses a short parameter URL, then targets clipboard, email or social link. Export creates that URL, requests the build once to surface a spinner/error, then navigates to the download URL. The double request is source-confirmed and can be simplified in PFL with a job/result API. The typewriter size and canned-text menus change CSS/font text without a new font compilation; editable textarea is the main live specimen.

**Not confirmed by static capture/source inspection:** exact rendered keyboard focus order, touch gestures, real loading duration, share clipboard success, responsive behavior, and empty states. Investigate against live UI only if necessary for V1 behavior; do not present guessed behavior as fact.

**Recommended V1 interaction contract:** drag updates a provisional preview at animation-frame cadence; commit on release/Enter; numeric field supports validation and keyboard; undo captures one gesture; reset and seeded random are undoable; glyph selection does not change global values; export uses the last validated state and reports progress/error. Handle missing glyph in chart/specimen explicitly.
