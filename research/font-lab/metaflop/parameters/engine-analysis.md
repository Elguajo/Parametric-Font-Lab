# Metaflop/Bespoke engine analysis

**Inspected locally at 2026-09-23:** `metaflop-www` HEAD `036c26b9f58f1264dba61d3818b7fae6869141e7` and `metaflop-font-bespoke` HEAD `35a9ff885fd3bb4e503b31910f347125df7d978a` in disposable `/tmp` clones. Source links use these SHAs. [Website](https://www.metaflop.com/) and [Bespoke page](https://www.metaflop.com/metafonts/bespoke) corroborate intent.

The Ruby/Sinatra web app reads `font.mf` declarations, maps METAFONT names to UI groups (`app/lib/font_parameters.rb`, `modulator_parameters.rb`), substitutes requested values in a per-session temp source, then runs `mf2outline.py` with timeout. The conversion invokes METAFONT/MetaPost-era geometry and FontForge to produce OTF/TTF/SVG; web export additionally uses `sfnt2woff`, `ttf2eot`, ZIP and bundled licenses ([config](https://github.com/metaflop/metaflop-www/blob/036c26b9f58f1264dba61d3818b7fae6869141e7/config/config.yml), [generator](https://github.com/metaflop/metaflop-www/blob/036c26b9f58f1264dba61d3818b7fae6869141e7/app/lib/font_generator.rb)). Preview is a server-built OTF embedded as base64 in CSS, not browser-computed paths. The checked-in site defines multiple font submodules; the capture selects **Bespoke**.

Bespoke `font.mf` defines global dimensional/proportional/shape/optical parameters, then includes `fontbase`, glyph files, and `ligkerndef`. Glyphs use hand-authored `beginadjchar`, pen positions, solved point relationships, `fill` and `penstroke` (e.g. [A](https://github.com/metaflop/metaflop-font-bespoke/blob/35a9ff885fd3bb4e503b31910f347125df7d978a/glyphs/uc/A.mf), [a](https://github.com/metaflop/metaflop-font-bespoke/blob/35a9ff885fd3bb4e503b31910f347125df7d978a/glyphs/lc/a.mf)). `fontbase.mf` defines T1 encoding, dimensional conversion, `normal_adjust_fit` sidebearing logic, superness curve macros, kerning class and ligature machinery. `ligkerndef.mf` contains class pairs and ligatures. Accented Latin glyphs and anchor arrays are present. No Cyrillic glyph subtree was found in this checked-out Bespoke source; official page explicitly says T1/Latin 256 characters. The inspected source does **not** emit UFO, Designspace or compatible variable masters.

Bespoke has optical corrections (`o#` overshoot, `apert`, `taper`, `corner#`) baked into glyph recipes. They are typography-specific, not a generic post-process. Spacing derives from per-glyph fit adjustments plus global unit metrics. Kerning is class-based at source level; quality across parameter extremes is unverified. The export command injects GPLv3/OFLv1.1 font metadata and web ZIP bundles both license texts. No license terms for copied page assets were found beyond code/component-specific notices; treat visual assets as reference only.
