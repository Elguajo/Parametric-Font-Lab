# Engine and ecosystem comparison

Accessed 2026-09-23. Exact repository HEADs are in [`sources/repositories.json`](../sources/repositories.json); licenses are separately checked in [`license-matrix.md`](../licenses/license-matrix.md). **Y** = documented/source-confirmed, **P** = partial, **N** = absent in inspected use, **?** = not confirmed. “Cyrillic” means the tool can *handle* Unicode glyphs, not that it supplies a Cyrillic design. All repositories resolved via `git ls-remote`; activity/maintenance level is not inferred from that alone.

| Project / role | Runtime/status | VF / Designspace / interpolation | Components / local axes / glyph editing | Kerning / Cyrillic / export | Fit and PCK cost |
|---|---|---|---|---|---|
| [Metaflop](https://github.com/metaflop/metaflop-www) + [Bespoke](https://github.com/metaflop/metaflop-font-bespoke) | Ruby/Sinatra UI + server METAFONT, historical Bespoke source | N / N / parametric regeneration | glyph `.mf` recipes / N / source-code editing | class kern / Latin T1 only / OTF, TTF, SVG, WOFF/EOT | UX/reference only; GPL and incompatible variable topology |
| [Fontra](https://github.com/fontra/fontra) | active browser editor + Python backend, in development | Y / Y via backends / Y | variable components / Y / Y | Y / Unicode user-authored / UFO, Fontra Pak, binary via compiler | excellent model inspiration, GPL makes embedding high-risk; separate editor only |
| [fontTools/varLib](https://github.com/fonttools/fonttools) | maintained Python library/CLI | Y / Y / Y | UFO components / no semantic local axes / no UI | feature/table tooling / Unicode / TTF, OTF, WOFF2 | core compiler and validation; low integration cost |
| [fontmake](https://github.com/googlefonts/fontmake) | Python CLI, actively released | Y / Y / Y through ufo2ft+varLib | UFO components / no local axes / no editor | feature compile / Unicode / static/variable TTF, OTF | primary build orchestrator; low cost, pin versions |
| [UFO spec](https://github.com/unified-font-object/ufo-spec) + [Designspace](https://fonttools.readthedocs.io/en/latest/designspaceLib/index.html) | interchange specifications, no runtime | Y / Y / master locations | components / not semantic local axes / file data | groups/features / Unicode / source formats | generated interchange layer; spec docs licensing unconfirmed |
| [opentype.js](https://github.com/opentypejs/opentype.js) | browser/Node JS parser/writer | variable-font read/instance Y / N / path transforms | reads components / no recipe-local axes / path API | basic metrics / Unicode cmap / OpenType/SVG paths | V1 outline inspector; validate parser and shaping limitations |
| [HarfBuzz](https://github.com/harfbuzz/harfbuzz) | C/C++ library, WASM wrapper available | variation shaping / N / N | outline API, not editing | Y / Y / glyph positions | optional shaping oracle; native CSS text first, add WASM for advanced proof |
| [Glyphr Studio 2](https://github.com/glyphr-studio/Glyphr-Studio-2) | Vite web editor | VF ? / Designspace N / interpolation limited | shapes/components / N / Y | Y / Unicode / TTF/OTF/WOFF, project | UX reference; GPL, beginner editor rather than parametric compiler |
| [FontForge](https://github.com/fontforge/fontforge) | desktop C/Python/CLI | variable/DS partial, not chosen pipeline | Y / N / Y | Y / Unicode / broad binaries | debugging/inspection only; whole-program GPL and heavy runtime |
| [BirdFont](https://github.com/johanmattssonm/birdfont) | Vala/GTK desktop | VF/DS not confirmed | editor components / N / Y | Y / Unicode / TTF, EOT, SVG | workflow reference; GPL and desktop integration cost |
| [Recursive](https://github.com/arrowtype/recursive) | OFL font source + Python scripts | Y / Y / curated masters | source components / authored axes / Y in source | Y / Latin repertoire in source / static + variable | architecture reference for mono/sans and multi-axis quality, no outline reuse |
| [Folent](https://github.com/mabugis/Folent) | React/Vite TS browser experiment | morphing SVG, not production VF / N / visual shape matching | extracted paths / per-glyph morph / N | N / loaded-font dependent / SVG font & SVG glyphs | useful A/B animation thought experiment; arbitrary morph cannot guarantee font validity |
| [fontc](https://github.com/googlefonts/fontc) | Rust CLI, active development | Y / Y or source adapters / Y | compilation focus / N / N | Y / Unicode / static/variable binaries | monitor as alternative compiler; second stack costs more than V1 needs |
| [Coldtype](https://github.com/coldtype/coldtype) | Python programmatic typography, alpha API | variable font use / DS ? / animations | paths / scripted local behavior / no full editor | HarfBuzz-based shaping options / Unicode / SVG/images, some font workflows | generative reference, not primary production font compiler |

Sources: [Fontra README](https://github.com/fontra/fontra/blob/main/README.md), [fontmake README](https://github.com/googlefonts/fontmake/blob/main/README.md), [opentype.js API](https://github.com/opentypejs/opentype.js), [HarfBuzz docs](https://github.com/harfbuzz/harfbuzz), [Glyphr](https://github.com/glyphr-studio/Glyphr-Studio-2), [BirdFont](https://github.com/johanmattssonm/birdfont), [Recursive build notes](https://github.com/arrowtype/recursive), [Folent README](https://github.com/mabugis/Folent), [fontc README](https://github.com/googlefonts/fontc), [Coldtype README](https://github.com/coldtype/coldtype). Some feature cells are deliberately “?” because no source-level proof was found; do not convert them to product commitments.

**Layer recommendation:** original recipe evaluator for geometry; native browser text for fast specimen, opentype.js for outline inspector; optional HarfBuzz when exact shaping proof matters; versioned JSON canonical source, generated UFO/Designspace; fontmake/fontTools for compilation; Fontra/Recursive for architecture study. Folent-style arbitrary path matching remains a visual-only experiment. No “best overall” ranking is meaningful across editor, compiler and font-source roles.
