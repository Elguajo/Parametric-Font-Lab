# Neutral V1 UI token proposal

Proposed (not copied from Metaflop): light neutral canvas `#f7f8f7`, surface `#fff`, subtle surface `#eef1ef`, ink `#19221e`, muted ink `#56615a`, 1 px border `#c9d3cb`, accent `#147d66`, error `#b43d3d`; verify contrast in implementation. System UI font for controls, generated font only in specimen. Type scale 12/14/16/20 px with 1.4–1.5 line height. Spacing scale 4/8/12/16/24/32 px; 4 px radius; 44 px touch target minimum, 32 px dense desktop row with accessible hit area. Rail 280–320 px, center flex min 360 px, chart 280–360 px; collapse by content constraints, not a fixed copied breakpoint.

State tokens: focus ring 2 px accent + offset, hover surface, selected accent tint, disabled muted, error border/text/icon, loading skeleton. Controls show numeric value, unit, min/max, reset; grouping borders and headings improve scanning. Do not copy Metaflop's pale green, all-lowercase text, Font Awesome branding or 14 px inputs.
